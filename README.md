# Tool Box

A utility suite built with React + Vite. 11 tools with no backend.

**[Live →](https://vyzzze.github.io/tool-box/)**

---

## Tools

| Tool | Description |
|---|---|
| **Color Palette** | Generate cohesive 5-color palettes with HEX / RGB / HSL / HSV / CMYK export |
| **Gradient Generator** | Visual CSS gradient builder with live code output |
| **Fancy Fonts** | Transform text into Unicode stylized variants |
| **Audio Visualizer** | FFT canvas visualizer — mic input or demo mode |
| **Background Remover** | Client-side background removal via drag & drop |
| **Unit Converter** | Length, weight, temperature, speed, area & data |
| **Word Counter** | Live text analysis — words, chars, sentences, read time, top words |
| **QR Generator** | URL or text → QR code with custom colors + PNG download |
| **Password Generator** | Cryptographically random via `crypto.getRandomValues`, with entropy scoring |
| **Markdown Previewer** | Zero-dependency live Markdown renderer — edit / split / preview modes |
| **Shadow Generator** | Visual `box-shadow` & `text-shadow` builder with multi-layer support |

---

## Stack

- React 18
- Vite 4
- Tailwind CSS 3
- Lucide React

No backend. No API keys. Everything runs in the browser.
